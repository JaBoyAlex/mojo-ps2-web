MOJO!LOCAL PREPARATION

ONE SETUP. YOUR GAME.

Make it yours.

Prepare a private runtime from your legally obtained MOJO! USA PS2 disc once. Import it into the player alongside your disc. Both stay on your device and can be remembered for later visits.

Why the extra step?

The compiled runtime includes translated game code. The public website supplies the player and preparation tools, while you create the game-specific runtime locally. No game data needs to be uploaded.

Prepare on Linux or Windows with WSL2

  1. Clone the linked source repository. Install CMake, Ninja, Python 3.11+, Clang 19, libc++ and the native dependencies documented in the README.
  2. Install and activate Emscripten 6.0.11.
  3. Run the build with your supported ISO or BIN/CUE. First-time preparation can take several minutes.
git clone https://github.com/JaBoyAlex/mojo-ps2-web.git
cd mojo-ps2-web
git clone --depth 1 --branch 6.0.11 https://github.com/emscripten-core/emsdk.git userdata/emsdk
userdata/emsdk/emsdk install 6.0.11
userdata/emsdk/emsdk activate 6.0.11
source userdata/emsdk/emsdk_env.sh
python3 scripts/build_web.py --game '/path/to/Mojo! (USA).cue'

The output is userdata/MOJO-runtime.mojo. Keep it private. Return to the player and choose that file, then choose your original BIN or ISO. A matching existing native engine can seed the exploration recordings; see the README.

Supported disc

USA PS2 · SLUS_207.41 · SYSTEM.CNF VER 1.02. The full disc and boot executable are checked. Other regions, revisions and altered images are rejected.

Your saves

Saves are remembered in browser storage. On supported browsers, link a .ps2 file once to automatically load and save back to the same file. Export your local save card before moving from localhost to this website: browser storage and file permissions are tied to each origin.
