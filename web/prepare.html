Enter your disc path and where to save the result. The helper installs the required build tools with Ubuntu administrator access, then prepares your game.

One import. Ready for next time.

  1. Choose your legally obtained USA ISO or single-track BIN/CUE in the helper.
  2. Leave the helper open while it prepares MOJO-runtime.mojo. Downloads and compilation can take a while and use several GB of disk space.
  3. Return to the player and select Import prepared .mojo file. Your included disc is verified and remembered locally.
  4. Click Play MOJO!. Later visits can use the remembered game, provided your browser data remains available.

The helper uses the existing runtime builder. It can reuse a verified local build, and keeps a local cache so retries do not start from scratch. No disc, translated game code, prepared game file, save or private log is uploaded. Keep your resulting .mojo file private.

Why is the helper needed?

The current runtime contains game-specific translated code, so selecting and extracting a disc on the website alone cannot create it. Preparation happens on your computer with the existing builder; the public site supplies the player and independent tools. The game itself is not distributed with these downloads. The Windows helper is unsigned and does not disable Windows security settings.

Automatic preparation currently supports Windows x64 with Ubuntu 24.04 on WSL2, and Ubuntu 24.04 Linux. A prepared file can be moved privately to another device with a compatible browser. macOS and mobile preparation are not supported by this helper.

Already have a prepared file, or prefer manual setup?

Existing runtime-only .mojo files still work. Import yours, then choose your disc separately when prompted. Developers can use the manual build instructions. The public helper source is available on GitHub.

Supported disc and save data

USA PS2 · SLUS_207.41 · SYSTEM.CNF VER 1.02. The complete image and boot executable are checked; other regions, revisions and altered images are rejected. Existing browser saves are kept. Link a save file on supported browsers to load and save in one location. Browser storage belongs to each website, browser profile and device; export your save before moving between them.
